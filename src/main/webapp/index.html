SmartCampusAPI — Postman Testing

Apache Tomcat · JDK 17 · NetBeans 24 · JAX-RS / Jersey
Base URL: http://localhost:8080/api/v1
GET Requests
GET http://localhost:8080/api/v1/ Discovery
Expected: 200 OK — returns version, links
GET http://localhost:8080/api/v1/rooms All rooms
Expected: 200 OK — returns array of rooms
GET http://localhost:8080/api/v1/rooms/1 Room by ID
Expected: 200 OK — single room object  |  invalid id → 404
GET http://localhost:8080/api/v1/sensors All sensors
Expected: 200 OK — returns array of sensors
GET http://localhost:8080/api/v1/sensors?type=temperature Filter by type
Expected: 200 OK — filtered sensor list
GET http://localhost:8080/api/v1/sensors/S1/readings Sensor readings
Expected: 200 OK — array of readings  |  unknown sensor → 404
POST Requests
POST http://localhost:8080/api/v1/rooms Create room
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "1",
  "name": "Lab A",
  "capacity": 40,
  "sensorIds": []
}
Expected: 201 Created — returns created room
POST http://localhost:8080/api/v1/sensors Create sensor (ACTIVE)
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "S1",
  "type": "temperature",
  "status": "ACTIVE",
  "currentValue": 0,
  "roomId": "1"
}
Expected: 201 Created — returns created sensor
POST http://localhost:8080/api/v1/sensors Create sensor (MAINTENANCE)
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "S3",
  "type": "temperature",
  "status": "MAINTENANCE",
  "currentValue": 0,
  "roomId": "1"
}
Expected: 201 Created
POST http://localhost:8080/api/v1/sensors Invalid roomId → 422
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "S2",
  "type": "humidity",
  "status": "ACTIVE",
  "currentValue": 0,
  "roomId": "999"
}
Expected: 422 Unprocessable Entity — room 999 does not exist
POST http://localhost:8080/api/v1/sensors/S1/readings Add reading (ACTIVE)
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "R1",
  "timestamp": 1713780000,
  "value": 26.5
}
Expected: 201 Created — returns reading object
POST http://localhost:8080/api/v1/sensors/S3/readings Add reading (MAINTENANCE) → 403
Header: Content-Type  →  application/json
Body — raw JSON
{
  "id": "R2",
  "timestamp": 1713780000,
  "value": 30.2
}
Expected: 403 Forbidden — sensor is in MAINTENANCE
DELETE Requests
DELETE http://localhost:8080/api/v1/rooms/1 Delete room (no sensors)
Expected: 204 No Content — room deleted
DELETE http://localhost:8080/api/v1/rooms/1 Delete room (has sensors)
Expected: 409 Conflict — room still has sensors attached
DELETE http://localhost:8080/api/v1/rooms/INVALID Delete room (not found)
Expected: 404 Not Found
